This is a Boot.dev guided project.

The aim of this project is to create a static site generator that converts Markdown files, static images and CSS styling into public webpages (served through GitHub pages).

The project contains placeholder files in the form of a "Tolkien Fan Club" website, inside the "docs/" folder. 
These need to be uploaded alongside the script so that GitHub pages can serve them, but they are entirely generated by a script in the program itself, build.sh. This folder is wiped by the script before being regenerated.

The pages themselves have different demonstrations of how the program handles different Markdown commands, such as blockquotes or code.
